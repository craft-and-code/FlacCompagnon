Crate flaccompagnon_spectrogram 

Source
Expand description

Streaming, channel-safe spectral measurements and deterministic PNG rendering.

No decoder, filesystem access, Tauri or application dependency. Callers feed interleaved PCM, then render the result with independently configurable labels, palettes and layout. PNG encoding preserves every rendered pixel losslessly.
