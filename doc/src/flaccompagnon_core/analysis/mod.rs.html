1//! The analysis chain: audio samples in, a verdict out.
2//!
3//! Everything here is internal machinery — no module in this folder is
4//! referenced from outside the crate, which is what made it possible to group
5//! them without touching a single caller. What crosses the crate boundary is
6//! the *result* ([`crate::types`], [`Detections`]), not the measuring.
7//!
8//! These nine modules were top-level files next to `report.rs`, `playlist.rs`
9//! and `scan.rs`, which made the crate root read as a flat pile where the
10//! export helpers and the DSP sat at the same level. They are one subsystem
11//! and they change together — a new detection touches the analyzer, a metric
12//! module and the verdict logic in one go — so they belong under one roof.
13//!
14//! ## Shape of the chain
15//!
16//! One pass over the samples, then one decision:
17//!
18//! * [`analyzer`] runs that single streaming pass and owns the state it needs
19//!   across packets. It is the only module here the decode paths talk to.
20//! * The per-metric modules do one measurement each and hold no session
21//!   state: [`spectrum`] (FFT, cut-off), [`bitdepth`] (effective depth),
22//!   [`stereo`] (dual-mono disguised as stereo), [`clipping`] (full-scale
23//!   runs), [`truepeak`] (inter-sample peaks, dBTP).
24//! * [`mdct`] and [`requant`] are the AAC-grid detection: the transform, then
25//!   the search for coefficients that fall back onto the quantization lattice
26//!   only an AAC encoder produces.
27//! * [`detections`] takes the finished measurements and turns them into the
28//!   verdict the UI shows. It is the only module here that decides anything;
29//!   the rest only measure.
30//!
31//! Keeping the measuring and the deciding apart is deliberate: a threshold
32//! that moves should move in [`detections`] alone, without touching the code
33//! that produced the number it compares.
34
35pub mod analyzer;
36pub mod bitdepth;
37pub mod clipping;
38pub mod detections;
39pub mod mdct;
40pub mod requant;
41pub mod spectrum;
42pub mod stereo;
43pub mod truepeak;
