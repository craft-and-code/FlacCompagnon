pub fn match_moved_files(
    missing: &[String],
    candidates: &[PathBuf],
) -> Vec<Relocation>
Expand description

Match each of missing against the files under root.

Only unambiguous, same-name matches are returned; a file with no candidate is simply absent from the result, and the caller reports how many were found rather than failing the whole operation. That matters for a listing spanning several folders: pointing at one of them should fix that folder’s files and leave the rest alone.

candidates is every path under the chosen folder — taking it as an argument rather than walking the disk here keeps this crate free of the directory traversal (and the traversal’s error handling), and lets the unit tests work on paths that never existed.
