pub fn cover_from_bytes(
    bytes: Vec<u8>,
    label: &str,

Expand description

Build a CoverArt from raw image bytes, from wherever they came from — shared by read_cover_file (a dropped image) and the online lookup’s downloaded artwork (src-tauri/src/lookup.rs). label is only used to identify the source in an error message (a file path, or a URL).
