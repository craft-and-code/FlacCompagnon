Module report 

Source
Expand description

Report generation: a spreadsheet-friendly CSV, and a re-importable JSON that round-trips the full FolderReport — every field the app computed, nested detections included — so a saved analysis can be dropped back onto the window later and rendered without re-decoding a single audio file.

Constants§

CSV_FILE_NAME
Default file name suggested when saving a report.
JSON_FILE_NAME
Same stem, JSON sibling — save always writes both from one dialog pick.
MAX_JSON_BYTES
Resource budget for an imported JSON report: 64 MiB, ample for large libraries. Both the metadata and the bytes actually read are checked, including files that grow while being read.

Functions§

build_csv
Build the CSV text for a folder report.
build_json
Build the JSON text for a folder report (pretty-printed, wrapped with a format marker and version — see JsonReport).
open_regular_file
Open a regular file without following links or accepting special files. The opened handle is validated because a concurrent rename could replace a previously checked file with a link or pipe. Unix opens are nonblocking.
parse_json
Parse a previously-saved JSON report back into a FolderReport, so it can be rendered without re-analyzing any audio. Rejects JSON that doesn’t carry FlacCompagnon’s format marker, with a message meant for end users (someone dropped an unrelated .json file).
read_json
Read a regular JSON report with a bounded allocation. The opened handle is checked, and Unix opens are nonblocking without following links, so a concurrent path swap cannot stall cache discovery.
validate_destination
Reject links and special files before replacing an export destination. A missing destination is allowed; its parent must exist when writing.
write_atomic_bytes
Atomically replace an exported file with bytes, rejecting links and special files. Renaming a sibling temporary file avoids truncating an existing export on an interrupted write, and never follows a destination link to an audio file.
write_csv
Atomically write the CSV report to dest, rejecting links and special files.
write_json
Atomically write the JSON report to dest, rejecting links and special files.
