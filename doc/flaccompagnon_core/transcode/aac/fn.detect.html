Expand description

Run the detector over one file’s decoded channels.

channels holds one slice per channel. Mono is analyzed directly; stereo is analyzed as L/R and as M/S and the higher score wins, because an encoder chooses between those two modes per frame and nothing in the decoded signal records which it picked. More than two channels: the first two are used, which is where a stereo master’s content lives.

cancelled is polled once per alignment so a long sweep can be stopped. Returns None when it fires, when the file cannot supply all requested frames, or when its sample rate has no tabulated bands.
