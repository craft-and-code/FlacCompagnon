# Discontinuity checks index

This page is retained for existing links. FlacCompagnon reports two independent sample-domain restoration cues:

- [Impulses](impulses.md): short, isolated pulse candidates that can sound like clicks.
- [Dropouts](dropouts.md): brief exact-zero gaps bounded by active audio.

Neither count changes the lossless-authenticity badge. Both provide places to audition, rather than a corruption verdict. Intentional transients, edits and silence can resemble damage; zero candidates does not prove that a recording has no defect.

The streaming detector processes decoded channels independently. Counts can exceed the number of locations saved in a report: only the first 32 locations of each kind are retained, ordered by time and channel. Simultaneous events on two channels are two channel events.
