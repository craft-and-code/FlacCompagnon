# Audio measurements index

This page is retained for existing links. The individual measurement pages are now separate so that method, interpretation, limits and fixtures stay next to the result they describe.

- [Stereo polarity](stereo-polarity.md)
- [Stereo balance](stereo-balance.md)
- [High-frequency stereo narrowing](high-frequency-stereo.md)
- [Integrated loudness](integrated-loudness.md)
- [Loudness range](loudness-range.md)

All five measurements are computed during the decoded audio pass. Polarity and balance require exactly two decoded channels. Integrated loudness and LRA currently accept mono or stereo at 8–768 kHz. A saved report from an older version remains readable, but it must be analyzed again to contain measurements added after it was created.
