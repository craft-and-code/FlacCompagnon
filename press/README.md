# FlacCompagnon press assets

The approved application mark is a rounded lowercase **f** with a lime point on the same dark surface used by Aède and Phémios. Keep its natural proportions, spacing and transparent outside corners.

## Logo files

- [Outlined SVG](logos/flaccompagnon-icon.svg): scalable artwork; no installed font or external asset is required.
- [1024 px PNG](logos/flaccompagnon-icon-1024.png): approved raster master for application-icon exports.
- [512 px PNG](logos/flaccompagnon-icon-512.png): approved preview and ready-to-use editorial image.

See the [brand guide](brand-guide.md) for colour values and usage. Website sharing artwork is available as [og-image.png](../site/assets/og-image.png).

FlacCompagnon checks audio authenticity and integrity through a native desktop application, a command-line interface and a reusable Rust analysis core. Analysis findings are evidence to interpret, not a guarantee of a recording's origin.

Website: <https://craft-and-code.github.io/FlacCompagnon/>. Related projects: [Aède](https://craft-and-code.github.io/aede/) and Phémios.
